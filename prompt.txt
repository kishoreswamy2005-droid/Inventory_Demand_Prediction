### Important ML limitations

The supplied notebook trains a model to predict `Units Sold` using contemporaneous tabular features.

It does not create lagged sales features such as:

- Lag 1.
- Lag 7.
- Lag 14.
- Lag 28.
- Rolling mean 7.
- Rolling mean 28.

Therefore, do not claim that the existing model is a complete multi-day forecasting engine.

Keep the supplied model as the baseline.

Create a separate, clearly documented future improvement path for leakage-safe time-series forecasting.

Any future lag features must be calculated separately for each Store ID and Product ID, shifted so that the prediction never uses the target value from the same day or future dates.

Use chronological validation.

Do not randomly split time-series records.
